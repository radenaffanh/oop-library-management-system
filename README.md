# Library Management System

Library management system in C++: books, staff, members, borrowing and returns.

## Features

- Book, staff and member lists
- Member status and borrowing count
- Borrowing and return forms with dates

## How to run

```bash
g++ library_management.cpp -o library_management
./library_management
```

## About

Built in **C++** for the OOP Practicum - assignment 1 course, Robotics and Artificial Intelligence Engineering.
